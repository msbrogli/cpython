Add sandbox resource limits to the :mod:`sys` module for executing untrusted
code with controlled resource limits. New functions include:
:func:`~sys.setsandboxlimits` and :func:`~sys.getsandboxlimits` for
configuring limits; :func:`~sys.getsandboxcounts` and
:func:`~sys.resetsandboxcounters` for monitoring; scope management via
:func:`~sys.addsandboxfilename`, :func:`~sys.removesandboxfilename`,
:func:`~sys.clearsandboxfilenames`, :func:`~sys.entersandboxscope`,
:func:`~sys.exitsandboxscope`, and :func:`~sys.issandboxinscope`;
:func:`~sys.suspendsandboxlimits`, :func:`~sys.resumesandboxlimits`, and
:func:`~sys.issandboxsuspended` for temporarily bypassing limits; and
:func:`~sys.setobjectcreationhook` and :func:`~sys.getobjectcreationhook`
for intercepting object creation. Limits can be set for integer digit count,
string/bytes length, collection sizes (list, dict, set, tuple), statement
execution count, and total GC-tracked allocations.
